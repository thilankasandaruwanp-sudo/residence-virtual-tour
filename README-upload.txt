RESIDENCE 082 — UPLOAD PACKAGE

Files:
- index.html: the website entry file.

Upload:
1. Open your GitHub repository.
2. Choose Add file > Upload files.
3. Upload index.html to the repository root (not inside a folder).
4. Commit changes to the main branch.
5. Ensure Settings > Pages uses GitHub Actions as the source.

The page loads Three.js and fonts from CDNs, so visitors need an internet connection.
The 3D model is an approximate concept based on the supplied reference images, not a verified architectural/BIM model or construction drawing.
